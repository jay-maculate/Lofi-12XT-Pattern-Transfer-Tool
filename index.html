Lofi-12XT Pattern Transfer Tool

What this tool does

This tool lets you copy patterns and their samples from one Lofi-12XT project into another.

How to use this tool

  1. Click Open SD card. Select the Lofi-12XT folder, then click Open. Do not open a folder inside it.
  2. Choose a project on the left and a project on the right. The numbers match the project slots on the device.
  3. Click a pattern to see its samples, waveforms, and playback. Click again to close it.
  4. Drag a pattern from one side to a slot on the other. Its samples are loaded into free slots. The wav files are copied only when that project does not already have them.
  5. The trash icon clears that pattern and any sample slots no other pattern uses. The wav files stay on the card. You must click OK to confirm.

Choose the Lofi-12XT folder

In the next window, select the Lofi-12XT folder on your SD card, then click Open (or Select Folder).

You do not need to open Project, Pool, or any folder inside it.
