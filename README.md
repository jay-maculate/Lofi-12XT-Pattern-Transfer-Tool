# Lofi-12XT Pattern Transfer Tool

https://jay-maculate.github.io/Lofi-12XT-Pattern-Transfer-Tool/

Move a pattern, and the samples it uses, from one Lofi-12XT project to another.

Open the page in Chrome or Edge, choose the folder called `System`  on the SD card, pick a project on each side, and drag a pattern across. Drop it on an empty slot to replace that slot, or drop it on an occupied slot to shift all patterns beneath it down.

As with any tool that overwrites data on your card, you should make a backup before using.
